# 评审部署与验证

## 环境

Python 3.11 或更新版本；Windows / Linux / macOS。安装依赖需要联网；安装完成后，示例体验不需要云端 AI。Git 用于查看历史，Node.js 仅用于运行图片几何检查。

下面命令均在参赛包的 `源码/` 目录执行。本地体验使用独立的数据目录，只监听本机回环地址，不依赖原作者服务器、域名、证书或特定数据盘。

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-review.txt
.\.venv\Scripts\python.exe review.py
```

### Linux / macOS

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-review.txt
.venv/bin/python review.py
```

打开 `http://127.0.0.1:8787`。示例账号：`demo`；示例密码：`Demo-video-2026`。该公开示例账号只存在于本地示例数据库，不适用于线上系统。终端按 Ctrl+C 停止。端口冲突时加 `--port 8879`。

## 两种体验模式

### 示例模式（默认）

`python review.py --mode demo` 创建独立的 `review-demo-data/`，包含 36 道合成题、复习记录和预置 AI 回应，便于快速查看图表与交互。图片示例在 `demo/assets/demo-question.png`。预置回应围绕这道泰勒极限示例，仅用于演示流程，不是面向任意上传题目的真实智能服务。

注意：示例模式中的模型测试、OCR、解题和追问使用本地预置适配器，不能据此评估模型准确性、响应速度或外部接口可用性。

### 真实运行模式

`python review.py --mode live` 启动正常应用，创建空白独立数据库 `review-live-data/`。首次生成的管理员账号和随机密码在该目录 `admin_password.txt`；如果启动环境预先设置了 `MATH_ADMIN_USER` / `MATH_ADMIN_PASSWORD` / `MATH_ACCESS_CODE`，则使用对应初始化设置。后续修改环境变量不会覆盖已创建账号的密码。

登录后到管理后台配置自己的 Base URL、模型、视觉模型和 API Key，测试连接后保存。具备视觉能力的模型才能识别图片；管理员可调整调用额度。新题固定自动识别归类；无自带解析时自动请求解答。真实调用可能产生模型服务费用，由评审自行选择是否启用。无需配置 AI 也能验证手工题库、科目、复习、打印和统计功能。

`--data-dir <路径>` 可指定另一个独立体验目录。不要指向任何线上数据库目录。

## 生产部署

`start.sh`、`backup.sh` 等是原服务器部署脚本，包含专用数据盘检查，**不是跨平台评审入口**。新服务器部署时应根据自己的数据路径、HTTPS 反向代理和进程管理环境配置，不应原样照搬历史服务器路径。`.env.example` 保留原配置示例供源码参考，评审启动器不读取它，也不需要复制真实 `.env`。

正式服务应使用 HTTPS，并保持 `MATH_COOKIE_SECURE=1`；评审入口仅因本机 HTTP 使用进程内 `MATH_COOKIE_SECURE=0`。评审启动方式不会修改线上启动脚本或 Cookie 设置。

## 功能验证清单

| 操作 | 预期结果 |
| --- | --- |
| 打开首页 | 小卡片按日期分组，默认不展开所有题目 |
| 点击题卡，再次点击 / 底部收起 | 题干与解答展开和收起 |
| 录入文字或上传示例图片 | 题目保存并自动整理；图片可裁剪、旋转后保存 |
| 上传 / 填写自己的解析 | 保留原解析，自动处理只识别题目与归类 |
| 切换自测模式 | 隐藏解答，按需对答案 |
| 从单题详情进入复习 | 回忆后看解答，记录四档掌握反馈与备注 |
| 搜索、筛选、星标 | 返回对应题目，保持题库归属 |
| 打开学习状况 | 饼图、柱图、热力图、知识点与相关题目可查看 |
| 「我的」新增 / 编辑科目 | 在录题、筛选和学习统计中同步显示 |
| 选题生成练习卷 | 可显示有解答 / 无解答版本并打印 / 另存 PDF |
| 导入导出、备份 | JSON 合并导入不覆盖相同 ID，服务器备份包含数据库和图片 |
| 管理后台 | 管理员可使用模型、邀请码和公告模块，普通用户不能越权 |

## 隔离回归检查

```bash
python tests/test_subjects.py
python tests/test_learning.py
python check_release.py
node tests/image-editor.test.cjs
```

以上 Python 检查创建自己的临时数据库，不使用真实用户数据。`tests/check_configured_ai.py` 是可选真实模型检查，不能当作离线回归直接运行；先阅读其用途并提供自有服务设置。

## Git 历史

`源码/.git/` 是实际 Git 仓库，包含提交对象、分支和标签。可执行：

```bash
git status
git log --oneline --decorate
git show v2.2.0
git fsck --full
```

评审副本移除了远程仓库地址，防止误向原项目推送；分支和版本历史保留。`recovered/v*` 是备份恢复的历史检查点，不保证每个早期提交都可独立部署。`v2.2.0` 是补建 Git 时的完整线上源码基线；后续提交包含视频制作与参赛交付工具。
