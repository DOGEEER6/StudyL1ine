# 数学错题本（Math Notes）

## 项目概述

数学错题本是一款面向自主学习的 Web 应用，将零散的文字题目、截图、手写解析和复习反馈收在个人题库中。手机端围绕「错题本、复习、记一题、学习状况、我的」五个入口设计；同时支持桌面浏览器。

本次提交的应用版本为 **v2.2.0**，附完整源码、Git 仓库、评审体验入口、自动检查脚本和功能演示影片。作品为可运行的软件系统，视频中的题目与统计为合成示例，AI 输出预置；评审可选择真实运行模式配置自己的模型服务。

## 要解决的问题

- 错题分散在相册和笔记中，查找、分类和二次复习费时。
- 只有答案而没有知识点整理，难以判断哪些章节反复出错。
- 首页堆满长题和解析，手机浏览不便，复习时也容易提前看到答案。
- 学习量与掌握情况缺少可追踪的记录。

## 核心功能

| 模块 | 实现内容 |
| --- | --- |
| 收题与原题保留 | 文字、LaTeX 公式、图片上传、粘贴 / 拖拽、图片压缩与校验 |
| 图片处理 | 裁剪范围、移动选区、左右 90° 旋转、取消 / 重置，应用后随题目保存 |
| 自动整理 | OCR 转写题干、极简标题、章节和知识点标签，失败状态与重试 |
| 解析策略 | 自带文字或图片解析时只识别归类；未提供解析时自动生成参考答案与解析 |
| 题库 | 按日期时间线、概述卡片展开收起、详情、编辑、删除、星标、搜索与组合筛选 |
| 学科 | 按账号新增科目、编辑名称，并同步到题目、筛选和统计 |
| 练习与复习 | 隐藏解答、自测对答案、到期复习、四档反馈、备注和下次复习安排 |
| 学习状况 | 掌握分布饼图、近两周录题 / 复习柱状图、17 周热力图、知识点掌握及相关题目跳转 |
| AI 追问 | 携带题目、已有解答和历史消息的连续对话 |
| 练习卷 | 选题或筛选后组卷，有解答 / 无解答版本、浏览器打印和另存 PDF |
| 账号与数据 | 邀请码注册、独立题库、修改密码、会话退出、JSON 导入导出、服务器备份 |
| 管理后台 | 系统概览、AI 模型配置与额度、用户与空间、邀请码、弹窗 / 顶部公告 |

## 设计与实现特点

1. **完整学习流程**：将收题、归类、练习、复习和学习反馈贯通，知识点可以直接跳回相关题目。
2. **保留用户思路**：自带解析不重复生成答案；题目原图和 OCR 文本均保留。
3. **依据学习记录统计**：掌握度来自题目状态和最新复习评分，显示评估覆盖情况；不是 AI 推测的考试分数。
4. **面向手机操作**：记题入口居中，长题默认收起，弹窗适应小屏和键盘，图片在本地裁剪旋转。
5. **轻量自托管**：Flask、原生 JavaScript、SQLite 和本地 KaTeX；不依赖云端题库存储。
6. **后台并发与一致性**：AI 任务队列限制并发，令牌阻止过期结果覆盖新编辑，处理中断可恢复。

## 真实能力与适用边界

- 这是浏览器 Web 应用，不是原生手机安装包。
- 真实 AI 功能需要配置可用的文本 / 视觉模型与凭据，并受服务可用性、模型能力和调用额度影响。图像识别与解答应人工核对。
- 当前预设课程目录重点覆盖数学分析和线性代数；自定义科目按实际题意整理章节。
- 复习安排属于应用规则，不代表学习效果或考试成绩保证。
- 评审包包含演示数据，不包含线上用户账号、题库、API Key、上传图片、证书及真实部署环境文件。
- `history:` 提交按已有备份恢复，不能代表最初逐行开发记录；从补建 Git 后的正常提交完整保留。

## 建议评审顺序

先阅读外层「开始评审.md」，观看 156 秒竖屏影片，再启动示例模式体验科目、时间线、自测和学习图表；需要验证真实模型请求时，使用独立的真实运行模式。技术实现、验证方式及版本历史见同目录文档。
