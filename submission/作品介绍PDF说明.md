## 生成与检查

使用 `build-introduction-pdf.py`、ReportLab 和微软雅黑系统字体生成 A4 八页 PDF；图片来自 `demo/screens/`，也可从演示制作素材包取得。该生成脚本只用于材料制作，不影响应用服务。

```bash
python submission/build-introduction-pdf.py --output <PDF路径> --screens <截图目录>
```

制作后使用 Poppler 逐页渲染，检查文字、表格、图注、页码与留白；另核对页数、图片数量、链接、关键词、字符和页面边界。生成环境需要安装 ReportLab；复现时需指定或调整可用中文字体路径，PDF 本身已嵌入字体。
