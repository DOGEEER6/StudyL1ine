# 技术实现

## 组成

```text
手机 / 桌面浏览器
  ├─ 原生 JavaScript：时间线、编辑、自测、复习、对话
  ├─ Canvas：图片裁剪旋转
  ├─ CSS / DOM：饼图、柱状图、热力图
  └─ 本地 KaTeX：数学公式
           │ 同源 HTTP / JSON / CSRF
Flask 应用 / Waitress
  ├─ 账号、权限、题库、附件、复习、打印、备份
  ├─ 科目、章节、标签与学习汇总
  └─ 限额与后台队列 → 可配置 AI / 视觉服务
           │
SQLite + 本地上传文件 + 备份 ZIP
```

## 代码导航

| 位置 | 责任 |
| --- | --- |
| `app.py` | Flask 路由、鉴权、上传处理、题库操作、AI 请求与后台任务、导入导出与备份 |
| `schema.sql` | 用户、题目、复习、对话、设置、额度和科目表 |
| `subjects.py` | 每账号科目与旧版题目表约束升级 |
| `learning.py` | 从题目、标签和复习记录计算学习汇总 |
| `templates/` | 首页、登录注册、学习页、后台、打印和错误页面 |
| `static/js/` | 原生前端交互、图像编辑、学习图表及管理界面 |
| `static/vendor/katex/` | KaTeX 公式渲染与字体，保留第三方许可文件 |
| `tests/`、`check_release.py` | 隔离的接口、学习统计、权限、迁移和图片几何检查 |

## 关键流程

题目保存先完成附件与文字校验，并保留原始题图。后台任务按实际内容判断是否已有解析：已有解析只转写题干、提取类型和知识点；没有解析才请求答案与解题步骤。结果使用结构化字段，任务令牌保证旧任务不能覆盖新编辑。失败显示原因，可重试。

科目按账号保存，内部 ID 与显示名称分离，改名不需要重写题目或复习历史。导出包含科目定义，导入按名称合并，兼容旧备份。

学习统计按当前用户的题目和最新复习结果聚合：掌握状态与评分参与知识点评估，显示未评估和覆盖数；活跃热力图来自逐日录题与复习记录。

## 数据与防护

账号密码使用 PBKDF2 哈希；写接口校验会话、CSRF 与请求来源；查询以用户 ID 隔离。图片限制体积、像素与数量，并在保存前检查与压缩。AI 使用额度限制，凭据不返回浏览器。SQLite 迁移使用事务，并检查外键；数据库与附件可打包备份。

这些是当前实现中的保护措施，不等同于完成第三方渗透测试或安全认证。真实 AI 服务会收到请求涉及的题目 / 图片 / 上下文，题库本身存放在自托管服务器。

## 已有验证与限制

仓库包含科目、账号隔离、导入导出、迁移保留复习 / 对话、自动解析策略、过期任务、防护与图像几何等检查；交付前会在解压副本再次运行，并把结果附在外层验证记录中。

历史提交来源见 `docs/VERSION_CONTROL.md`；不存在的中间编辑未伪造补齐。示例适配器不是模型训练成果。项目不包含模型权重，不宣称自主训练 OCR 或大语言模型。
