# 第三方组件

应用使用的第三方组件保留各自版权与许可，不作为本项目自行研发的算法、模型或字体成果。

| 组件 | 使用方式与声明 |
| --- | --- |
| Flask 3.1.3 | Python Web 框架；通过 pip 安装，版本见 `requirements.txt`，许可随其发行物提供 |
| Waitress 3.0.2 | Python WSGI 服务；通过 pip 安装，许可随其发行物提供 |
| Pillow 11.3.0 | 图片验证、压缩与变换；通过 pip 安装，许可随其发行物提供 |
| tzdata 2026.5 | Windows 的 IANA 时区数据支持；通过 `requirements-review.txt` 安装，许可随发行物提供 |
| KaTeX 0.16.22 | 仓库内托管的公式渲染资源；上游 MIT 许可全文见 `static/vendor/katex/LICENSE` |
| KaTeX 字体 | 字体内嵌声明指向 SIL OFL 1.1；正文与各字体版权 / 保留名称分别见 `static/vendor/katex/fonts/OFL.txt`、`FONT-NOTICES.txt` |
| NumPy、imageio-ffmpeg | 可选的视频制作依赖，不是运行应用所必需；按各自发行物提供的许可使用 |

许可文本来源：

- [KaTeX v0.16.22 LICENSE](https://github.com/KaTeX/KaTeX/blob/v0.16.22/LICENSE)
- [SIL OFL 官方文本](https://openfontlicense.org/documents/OFL.txt)

视频配乐由制作脚本按音符合成，未包含第三方录音或歌曲采样。渲染时使用制作电脑的中文系统字体，压缩包没有分发该系统字体文件。影片中的界面来自本系统，题目与统计使用合成演示数据。
