# 手机端功能演示影片

本目录是宣传视频制作工具，不属于线上服务启动流程。应用逻辑、线上数据库和用户内容均不修改。

## 成片

- 9:16 竖屏，1080 × 1920，60 fps，156 秒，H.264 / AAC，MP4 faststart。
- 浅蓝主题，真实手机界面截图、中文章节字幕、缓动转场、点击提示和学习页连续滚动。
- 配乐为本次使用音符合成的原创轻电子器乐：108 BPM，Dm / B♭ / F / C 和声，电钢琴音色、氛围和弦、低音与轻鼓。未使用第三方录音、歌曲或采样。无旁白。
- 最终输出位于聊天工作区的 `outputs/`：视频、封面、分镜预览、WAV 配乐和说明。

## 演示数据与处理方式

`serve_demo.py` 使用独立的 `render-data/` 数据库，36 道合成题和复习记录，仅监听本机 `127.0.0.1:8879`。演示账号、密码和假的模型标识仅用于该本机夹具。

AI 输出通过演示适配器预置，不读取真实凭据，不调用云端 AI，不访问线上题库。画面由真实应用界面实际操作后采集，再做动效剪辑，**不是一镜到底的实时录屏，也不表示真实 AI 响应速度**。视频全程注明「演示题目及 AI 结果为示例」。

## 复现

1. 安装项目依赖，并安装 `numpy Pillow imageio-ffmpeg`。字体使用 Windows 的微软雅黑；在其他操作系统运行需在 `render_video.py` 和 `serve_demo.py` 指定可用中文字体。
2. `python demo/serve_demo.py` 启动隔离演示。浏览器用 390 × 844 视口采集 `storyboard.json` 中列出的功能状态，保存到 `demo/screens/`。
3. `python demo/render_video.py --preview` 生成分镜与封面；`python demo/render_video.py` 生成带原创配乐的 60 帧成片。
4. 核验时长、分辨率、帧率和音轨，抽查每个章节及滚动与转场，检查结尾完整、声音不削波。

`screens/`、`render-data/` 和 `render-cache/` 不进入 Git；脚本和分镜进入 Git。交付素材包另附本次界面截图，可与仓库源码一起复现。

## 功能覆盖

账号登录与邀请码注册；题目概述卡片、展开收起、详情；文字 / 公式录题；图片上传、OCR、原图留档；裁剪旋转；自动标题 / 章节 / 知识点归类；自带解析策略；题目 AI 连续追问；隐藏解答自测；单题复习、四档评分、备注及复习计划；搜索、筛选、星标；学习分布、柱状图、热力图、知识点掌握；科目新增和改名；选题练习卷及打印 / PDF；JSON 导入导出和备份；管理员概览、AI 引擎、用户、邀请码、公告；账号设置。
